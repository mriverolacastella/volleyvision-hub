# VolleyVision Hub PRO

App Streamlit para análisis postpartido y prepartido de archivos DataVolley `.dvw`.

## Módulos principales

- General / Match Report
- Data Quality
- Post Match Report
- Ataque
- Saque
- Recepción
- Bloqueo
- Colocador / Setter Lab
- Money Time
- Por Set
- Match Plan
- Player Sheet
- Vídeo / Clips
- Objetivos / Semáforos
- Exportación Excel

## Uso

1. Sube uno o varios archivos `.dvw`.
2. Cambia entre vista individual y acumulado por equipo.
3. Revisa Data Quality antes de tomar decisiones.
4. Usa Match Plan y Player Sheet para preparar partido.
5. Exporta el contenido a Excel.
