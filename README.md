# VolleyVision Hub PRO

Aplicación Streamlit para análisis prepartido y postpartido de archivos DataVolley `.dvw`.

## Módulos principales

- General / Match Report
- Calidad de datos
- Post Match Report
- Centro de decisiones
- Rotaciones
- Producción / Tendencia
- Ataque
- Saque
- Recepción
- Bloqueo
- Colocador / Setter Lab
- Match Plan
- Objetivos / Semáforos
- Exportar

## Notas

Esta versión elimina las pestañas Por Set, Player Sheet y Vídeo / Clips para centrarse en el motor estadístico y táctico. El análisis de tramos del set está integrado dentro de los selectores de los módulos principales.
