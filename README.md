# VolleyVision Hub

Aplicación Streamlit para analizar archivos DataVolley `.dvw`.

## Funciones principales

- Carga de uno o varios partidos `.dvw`.
- Match Report visual por equipo y jugador.
- Ataque: eficiencia por zona y direcciones.
- Saque: eficiencia, tipos y direcciones.
- Recepción: análisis por zona, receptor y tipo de saque.
- Bloqueo: ranking, rotaciones y cruce con ataque rival.
- Colocador / Distribución: salidas tácticas y jugadas más usadas.
- Match Plan: recomendaciones de rotación inicial, saque, bloqueo-defensa y tendencias del rival.
- Exportación a Excel.

## Ejecución local

```bash
pip install -r requirements.txt
streamlit run app.py
```
